# پنل سبک VLESS برای Railway

پنل فارسی و کم‌حجم برای نمایش **دقیقاً سه کانفیگ ثابت VLESS + WebSocket + TLS**. در اولین اجرا سه شناسه ساخته می‌شود و در دیتابیس ذخیره می‌ماند؛ هر کانفیگ از نظر حجم و زمان نامحدود است. پنل هیچ فرم ساخت/ویرایش/حذف کاربر، ربات تلگرام یا ورود با رمز ندارد.

## نصب روی Railway

1. محتویات پروژه را در یک مخزن GitHub قرار دهید و در Railway از آن سرویس بسازید.
2. یک Volume با مسیر `/data` متصل کنید تا سه شناسهٔ تولیدشده در Deployهای بعدی ثابت بمانند.
3. (اختیاری) متغیر `DOMAIN` را روی دامنهٔ عمومی تنظیم کنید. در غیر این صورت `RAILWAY_PUBLIC_DOMAIN` استفاده می‌شود.
4. Railway مقدار `PORT` را به برنامه می‌دهد؛ نیازی به تنظیم دستی آن نیست.
5. پس از Deploy پنل در `/panel` و بررسی سلامت در `/health` در دسترس است.

متغیر اختیاری `DB_PATH` به‌طور پیش‌فرض `/data/omid3r.db` است.

## اجرای محلی

```bash
python -m pip install -r requirements.txt
DB_PATH=./omid3r.db DOMAIN=localhost:8000 python main.py
```

سپس `http://localhost:8000/panel` را باز کنید.

## نکتهٔ مهم دسترسی

برای خواستهٔ شما احراز هویت پنل حذف شده است. بنابراین **هر فردی که دامنهٔ Railway را بداند می‌تواند هر سه لینک VLESS را ببیند و استفاده کند**. لینک‌ها مثل کلید دسترسی‌اند؛ آن‌ها را عمومی منتشر نکنید. خود VLESS سه شناسهٔ مستقل دارد، اما پنل سقفِ «سه کاربر انسانیِ هم‌زمان» را نمی‌تواند دقیق تشخیص دهد: یک کاربر VLESS معمولاً چند اتصال شبکهٔ هم‌زمان باز می‌کند و بستن اتصالات اضافه باعث خرابی وب‌گردی می‌شود. برای سقف سخت تعداد کاربران باید لایهٔ دسترسی جداگانه یا سازوکار احراز هویت اضافه شود.

## سازگاری با نسخهٔ قبلی

اگر دیتابیس قبلی در `/data/omid3r.db` باشد، هنگام اولین اجرا حداکثر سه UUID فعال VLESS قبلی (بر اساس قدیمی‌ترین تاریخ ساخت) به سه جایگاه ثابت منتقل می‌شوند؛ اگر کمتر از سه مورد وجود داشته باشد، جایگاه‌های باقی‌مانده UUID تازه می‌گیرند. داده‌های دیتابیس قدیمی حذف نمی‌شوند، اما فقط همان سه UUID در تونل جدید پذیرفته می‌شوند. UUIDهای انتخاب‌شده پس از آن ثابت می‌مانند.

## ساختار

- `main.py`: اپ FastAPI و تونل VLESS TCP/UDP
- `vless.py`: ساخت لینک و پارس هدر VLESS
- `database.py`: نگهداری پایدار سه شناسه در SQLite
- `templates/` و `static/`: پنل تک‌صفحه‌ای سبک
- `Dockerfile`, `railway.json`: راه‌اندازی روی Railway
